# Week 01 — Bug Dodger

## Goal
Build a simple browser game using vanilla HTML, CSS, and JavaScript.

## Game: Bug Dodger
- Player controls a glowing square at the bottom of the screen
- Bugs (🐛) fall from the top at increasing speed
- Arrow keys move the player left/right
- Score increases over time
- Game ends on collision — restart button provided

## Key Learnings
- `requestAnimationFrame` loop for smooth 60fps rendering
- Collision detection using bounding box (AABB)
- CSS animations and keyframes for visual polish
- Dynamic difficulty scaling over time
