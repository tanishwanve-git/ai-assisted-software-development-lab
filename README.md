# AI-Assisted Software Development Lab

A collection of AI agents, browser games, and experiments built week by week.

## Structure

```
agent-lab/
  01-llm-api-call/    → Basic LLM completion script
  03-tool-calling/    → Interactive agent loop with tools, personas, and budget guardrails
games/
  week-01/            → Bug Dodger
lab-notes/
  week-01.md          → Notes from week 1
  week-03.md          → Notes from week 3
```

## How to Run

- **Games**: Open any `index.html` file directly in your browser.
- **Agent Lab**: Navigate to the module directory (e.g., `agent-lab/03-tool-calling`) and run `python3 main.py`.
